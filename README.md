# esnt-backend-ferreteria

Backend API para ferreteria construido con Node.js, TypeScript y Express.

## Requisitos

- Node.js `v22.22.1`
- npm `10.9.4`

## Instalacion

```bash
npm install
```

## Variables de entorno

```bash
cp .env.example .env
```

## Scripts

```bash
npm run dev
npm run build
npm start
npm run lint
npm run format:check
```

## Endpoints iniciales

- `GET /`
- `GET /api/health`
